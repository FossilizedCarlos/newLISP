# Synthetic release measurements — 2026-11-05

## Decision

Keep `MODE=baseline` (`-O1 -g`) as the default. Add explicit `release-o2`, `release-o3`, and `release-lto` options.
Neither session meets the predefined five-percent improvement threshold.
`-O2` reduces the geometric mean of elapsed-time ratios by 4.91% and 4.48%.
ThinLTO has a 5.02% FFI regression in session 1. The FFI measurements also have the greatest variation.
These results support explicit options, but do not establish a default change or real-application gains.

## Environment and method

- Hardware: Apple M5; memory: 34359738368 bytes.
- System: ProductName:		macOS; ProductVersion:		27.0.1; BuildVersion:		26A434.
- Compiler: Apple clang version 21.0.0 (clang-2100.3.34.2).
- Interpreter source: `e56e6f0d46c47357d95d66fa3f0447cac816f800`; item 12 adds the build modes and benchmark files.
- Flags: baseline `-O1 -g`; O2 `-O2 -g`; O3 `-O3 -g`; ThinLTO `-O3 -g -flto=thin`.
- Each candidate passes forced core QA and embedding checks before measurement.
- All six workloads also pass under ASan and UBSan at scale one.
- Each session uses scale ten, one warmup per pair, and nine measured runs per pair.
- Session seeds: 20261105 and 20261106. Each round shuffles all candidate/workload pairs.
- Sessions run sequentially on one machine. No compilation runs during measurement.
- Elapsed time includes process startup and result checks. Peak RSS is measured per process.
- Geometric means use equal weights for the six ratios to the same-session baseline.
- MAD means median absolute deviation. It describes variation, not a confidence interval.

See [the procedure](../README.md) for build and measurement commands.
Use `--seed 20261106` for the second session.
Raw JSON includes all samples, checksums, binary sizes, SHA-256 hashes, and environment details.
The two sessions use the same binaries and workload files.

## Limits

These are six synthetic workloads on one Apple M5 with one compiler version.
There is no control for all operating-system activity, power state, or thermal variation.
Two sessions on this machine do not establish results for other Macs or applications.
No interpreter internals change in this item. PGO and native profiling remain separate plan items.
